# Daph - Terminal Music Player

A simple terminal-based music player for a local audio collection.

## Controls

### Navigation
- `j` - Move down in track list
- `k` - Move up in track list

### Playback
- `:` - Play selected track
- `Space` - Play/pause current track
- `n` - Next track
- `p` - Previous track

### Seeking
- `<` - Seek backward 5 seconds
- `>` - Seek forward 5 seconds

### Volume
- `K` - Volume up
- `J` - Volume down

### Search
- `/` - Enter search mode
- Type to search by song title or artist
- `Enter` - Submit search
- `Esc` - Exit search mode

### Other
- `D` - Delete selected track from playlist
- `Esc` - Quit application

Supports MP3, FLAC, and WAV audio files.
